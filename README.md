# Coffee Shop Sales Analysis Dashboard

##  Project Overview

This project uses Microsoft Excel to analyze coffee shop transaction data and present sales information through an interactive dashboard.

The goal is to explore sales performance, identify useful business trends, and present data in a clear and understandable format.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Interactive Slicers
- Data Visualization
- Data Analysis

## Project Files

| File | Description |
|---|---|
| `CoffeeShopDashboard.xlsx` | Excel workbook containing the dashboard, transaction data, and supporting insight sheets. |

## Project Objectives

- Analyze coffee shop transaction data.
- Explore sales performance and trends.
- Organize data into meaningful summaries.
- Present information through an interactive Excel dashboard.
